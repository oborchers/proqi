# README demo storyboard

The primary README recording is a focused Proqi view. The static problem
diagram carries the integration relationship because two terminal panes become
too small at the rendered README width.

1. Begin at a clean shell prompt and type `proqi` visibly.
2. Open a prepared, isolated session containing realistic follow-up prompts, a
   clickable URL, a natural multiline checklist, an image attachment, and
   folded multiline context.
3. Move focus across the board so the selected surface, URL styling,
   `[Image 1]`, and `[Pasted text · …]` are visible in turn.
4. Delete an intentionally temporary thought and show the stable next focus.
5. Create a new thought in three visible text-entry steps.
6. Return to board mode, reopen the thought, and append a clarification.
7. Reorder the thought twice, select it with its neighbor, copy the ordered
   multi-selection, and leave the success state visible.
8. End on the composed board without build output, private data, or live network
   behavior.

The fixture creates annotations through the real paste path, then uses the real
release binary and deterministic state below the system temporary directory.
It never impersonates a named agent integration. The recording answers the
same bounded OSC palette probe as the reference dark terminal, then captures
Proqi's actual 24-bit ANSI output with Asciinema and renders it with `agg`.
